  SMO reaches NETCONF: {{ .Values.smo.advertisedHost }}:{{ .Values.smo.netconfPort }}  (service type {{ .Values.service.type }})

Verify:
  1) Pod up:
       kubectl -n {{ .Values.namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  2) Service / external IP:
       kubectl -n {{ .Values.namespace }} get svc {{ include "o1adapter.fullname" . }}
  3) Telnet reachable from the adapter pod (should connect):
       kubectl -n {{ .Values.namespace }} exec deploy/{{ include "o1adapter.fullname" . }} -- \
         bash -lc "timeout 3 bash -c '</dev/tcp/{{ .Values.telnet.host }}/{{ .Values.telnet.port }}' && echo TELNET_OK"
  4) From the SMO host, NETCONF mount target reachable:
       nc -vz {{ .Values.smo.advertisedHost }} {{ .Values.smo.netconfPort }}
  5) Adapter logs (telnet connect + pnfRegistration):
       kubectl -n {{ .Values.namespace }} logs deploy/{{ include "o1adapter.fullname" . }} -f
